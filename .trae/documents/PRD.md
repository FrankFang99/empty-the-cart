# 多巴胺购物平台 PRD文档

## 1. 产品概述

**多巴胺购物平台**是一个模拟购物体验的Web应用，让用户体验"清空购物车"的快感而不实际花钱。灵感来源于韩国的"dopamine shopping"网站，帮助冲动消费的年轻人获得购物满足感同时保护钱包。

- **目标用户**: 年轻消费者、购物爱好者、想要体验购物快感的人群
- **核心价值**: 提供真实购物体验的模拟，满足心理需求，避免实际支出

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱/用户名注册 | 浏览商品、加入购物车、模拟下单、发表评论、点赞评论 |
| 游客 | 无需注册 | 浏览商品、查看评论（无法互动） |

### 2.2 功能模块

1. **首页**: 商品分类导航、推荐商品展示、搜索功能
2. **商品列表页**: 分类筛选、商品卡片展示、排序功能
3. **商品详情页**: 商品信息、加入购物车、用户评论、点赞评论
4. **购物车页**: 商品管理、数量调整、模拟结算
5. **订单页**: 订单列表、订单状态、订单详情
6. **支付成功页**: 动画庆祝、清空购物车提示
7. **用户中心**: 个人信息、订单历史、收藏商品

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 导航栏 | Logo、搜索框、分类导航、用户登录入口 |
| 首页 | Hero轮播 | 商品推荐轮播图，自动切换 |
| 首页 | 商品专区 | 数码电器、服装鞋包、食品生鲜、美妆护肤四大专区入口 |
| 首页 | 推荐商品 | 热门商品卡片展示，点击进入详情 |
| 商品列表页 | 筛选栏 | 价格区间、品牌、销量筛选 |
| 商品列表页 | 商品网格 | 商品卡片网格布局，显示图片、价格、销量 |
| 商品详情页 | 商品信息 | 商品图片、名称、价格、描述、规格选择 |
| 商品详情页 | 评论区域 | 用户评论列表、发表评论、点赞评论 |
| 购物车页 | 商品列表 | 已选商品、数量调整、删除商品 |
| 购物车页 | 结算区域 | 总价显示、模拟结算按钮 |
| 支付成功页 | 动画效果 | 烟花/庆祝动画、清空购物车提示 |
| 订单页 | 订单列表 | 订单卡片、状态显示、操作按钮 |

## 3. 核心流程

### 3.1 用户购物流程

用户进入首页 → 浏览/搜索商品 → 查看商品详情 → 加入购物车 → 查看购物车 → 模拟结算 → 支付成功动画 → 查看订单

### 3.2 评论互动流程

用户登录 → 查看商品详情 → 发表评论 → 其他用户看到评论 → 点赞评论

## 4. 用户界面设计

### 4.1 设计风格

**方案A: Trae风格**
- 主色调: 深色背景 + 明亮渐变强调色
- 按钮风格: 圆角、渐变填充、微动效
- 字体: 现代几何字体
- 布局: 卡片式、流畅动画过渡
- 特色: 科技感、现代感、独特品牌标识

**方案B: 淘宝风格**
- 主色调: 橙色(#FF5000)为主，白色背景
- 按钮风格: 圆角、实色填充
- 字体: 系统字体，清晰易读
- 布局: 网格商品卡片、顶部导航
- 特色: 熟悉感、亲切感、国内用户习惯

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 导航栏 | Logo居左、搜索框居中、用户头像居右，固定顶部 |
| 首页 | Hero轮播 | 大图轮播，渐变遮罩，指示器 |
| 首页 | 专区入口 | 四个彩色卡片，图标+文字，横向排列 |
| 首页 | 商品卡片 | 图片+价格+名称，hover放大效果 |
| 商品详情页 | 商品图 | 大图展示，缩略图切换 |
| 商品详情页 | 评论区 | 头像+用户名+评论内容+点赞按钮 |
| 购物车页 | 商品行 | 图片+名称+数量调整+删除按钮+价格 |
| 支付成功页 | 动画区 | 烟花粒子动画，成功提示文字 |

### 4.3 响应式设计

- **桌面端优先**: 完整功能展示，多列布局
- **移动端适配**: 单列布局，底部导航，触摸优化
- **断点**: 768px(平板)、480px(手机)

### 4.4 动效设计

- **页面切换**: 淡入淡出过渡
- **商品卡片**: Hover放大、阴影增强
- **加入购物车**: 飞入动画
- **支付成功**: 烟花粒子、庆祝文字弹跳
- **评论点赞**: 心形动画、数字跳动

## 5. 商品数据

### 5.1 商品分类

| 专区 | 子分类示例 |
|------|------------|
| 数码电器 | 手机、电脑、耳机、相机、智能手表 |

- 商品描述
- 规格选项

## 6. 用户互动功能

### 6.1 评论系统

- 用户可发表商品评论
- 评论内容: 文字 + 可选表情
- 评论展示: 时间排序、点赞排序
- 评论互动: 点赞、回复(可选)

### 6.2 点赞系统

- 每条评论可被点赞
- 点赞数实时显示
- 用户可取消点赞
- 点赞动画反馈

- 响应式: 移动端适配
